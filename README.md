This repository contains my personal portfolio website.

## What's in this repo

- `portfolio-site/` - the portfolio website source
- `portfolio-site/index.html` - page structure and content
- `portfolio-site/styles.css` - visual design and layout
- `portfolio-site/app.js` - small UI interactions
